# 骰迹 · 玩法测试原型

根据《骰迹 · 完整玩家规则 v2》制作的纯静态网页原型,用于快速测试玩法可行性与游玩性。
无美术素材,全部用纯色与简约图形代替;无服务器,多人线下聚在一起共用一个窗口游玩。

## 本地运行

直接用浏览器打开 `index.html` 即可(纯静态,无构建步骤)。

## 部署到 Vercel

1. 推送本仓库到 GitHub。
2. 在 [vercel.com](https://vercel.com) 导入该仓库,Framework Preset 选 **Other**,
   构建命令留空,输出目录留空(根目录即静态站点),直接 Deploy。

或使用 CLI:

```bash
npx vercel --prod
```

## 游玩方式(单窗口多人)

1. 设置界面选择人数(1~6)、名字、获胜星星数(默认 3),开始游戏。
2. 每轮自动为所有玩家投出全部骰子(结果公开)。
3. 各玩家依次在自己的面板上点击骰子,放入**移动槽**(蓝)与**资源槽**(黄),
   必须是两颗不同的骰子;点击已放置的骰子可切换/取消。按「确认选择」锁定,
   确认后槽位显示 `?` 对其他人保密,全部确认后自动公开并结算。
4. 结算顺序:先得资源 → 严格顺时针移动(只结算最终落点)→ 工坊/星星弹窗决策 →
   轮末移星、检查胜利。

## 规则实现要点

- 18 格环形地图,S=START;每人 1 枚棋子 + 3 颗 D4,资源 0、星星 0。
- 工坊(精确停靠,每次限 1 个操作):买 D4(6 资源)/ D4→D6(4 资源)/ D6→D8(7 资源),D8 为最高级;新骰下一轮生效。
- 当前星星(精确停靠):支付 8 资源得 1 星;多人同轮命中且都支付,每人各得 1 星;有人购买后轮末随机移到另一个候选位。
- 资源无上限可储存;本轮新资源可立刻消费;未入槽的骰子本轮无效但不会消失。
- 先到目标星数者胜,同轮达成共享胜利。

## 与 PDF 的差异 / 假设

规则 PDF 第 6 页地图示意中 9~12 号格被文字框遮挡,本原型假设:

- 工坊格:**5、12**(12 为假设,与 5 大致对称)
- 星星候选位:**2、8、14、17**(可见部分)

如需调整,改 `app.js` 顶部的 `WORKSHOPS` / `CANDIDATES` 常量即可;
各类费用同样是顶部常量,方便调参测试。
