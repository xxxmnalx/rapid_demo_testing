# 地图生成原型（`mapgen/`）

《We'll Be Right Back》下水道地图的生成规则原型：在网页上调参数、看结果，规则定下来以后再写进 Unity。
单文件页面，内含全部 CSS 和 JS，无构建步骤，不发任何网络请求；双击 `index.html` 就能离线打开。

线上入口：`www.xxxmnalx.com/game/mapgen`。页面设了 `noindex`，主页不放入口。

## 生成分三层

1. **关系图（节奏）**：从入口到供电室的主路，主路上长出分支；维修间、赌场按深度挂成单出口的叶子；再按权重给其余房间定类型。
2. **门对门摆房间（空间）**：在 3 m 格子上从入口往外，每间房接到上一间房的空门上，门直连或接一段走廊（可以拐一次弯）。
   摆不下就换门、换大小、换朝向；还不行就用派生种子整张重来，最多 20 次。
3. **走廊补环**：在空格子里找路（每格 1 分，拐弯另加分，取总分最低），把离入口步数差得够多的两间房连起来，
   或者接到已有走廊的中间形成 T 字口。

页面上的参数、种子都写在链接的 `#` 后面，复制链接发给别人，打开就是同一张图。

## 和 Unity 版本的区别

- 随机数不同（这里用 mulberry32，游戏用 `System.Random`），同一个种子在游戏里不是同一张图。
- 房间尺寸来自地图策划的房间规则表；还没定的数值（房间 1、入口大小、走廊长度、各类房间的配比）用规则表"示例"列的占位值。
- 只生成单层，不管敌人、灯光、通风管。

## 测试

```bash
node mapgen/tests/core_test.mjs
```

8 组参数各跑 500 个种子，检查：房间和走廊不重叠、入口下方（安全屋一侧）没有东西、走廊格子连续、出口数不超过房间上限、所有房间连通、同一个种子两次生成结果相同。
